# 🏥 Hospital Master System

A comprehensive hospital management application built in Java. This project was developed to manage core hospital data while practically applying and comparing different data structures.

## ⚙️ The Technical Challenge
The core focus of this system was to manage patient and hospital data efficiently. To do this, I engineered the system utilizing both **Array Lists** and **Linked Lists**. 

Rather than just making it work, I ran performance tests to compare the execution times of both data structures when handling different types of hospital data (like adding new patients vs. searching for existing records). 

## 🛠️ Built With
* **Language:** Java
* **Concepts:** Object-Oriented Programming (OOP), Data Structures, Performance Testing

## 🚀 Key Features
* Patient record management and tracking.
* Efficient data retrieval using optimized data structures.
* Comparative execution time logging between Array Lists and Linked Lists.

## 🧠 What I Learned
Building this system solidified my understanding of how choosing the right data structure directly impacts software performance. I learned exactly when an Array List is faster for data retrieval, and when a Linked List is better for data manipulation.
